Manual de Uso (Terreno) — SinterkProyectos

Última edición: 25-09-2026

En este documento, se explica el uso de este sitio para los usuarios de terreno. Esto incluye registro de material utilizado, subida de fotos, información por punto. Para evitar confusiones, el personal de terreno tiene acceso a proyectos que tienen asignado.

01 · ATT

Gestión de proyectos de telecomunicaciones (OTT) — desde la creación hasta el informe final.

Para ATT, la información que se debe subir desde usuarios de terreno es la de material, y registro fotográfico cuando corresponda.

  • Sección de logística
  • Material

Cada material que sale en la OTT, Tiene las siguientes secciones:

  • Descripción: Nombre por SAP de cada material.
  • SKU: Se selecciona el material, se puede buscar según SKU o nombre del material. Se puede asignar un nombre alternativo (por ejemplo, en el caso del pantallazo el sku 69971 tiene el nombre común de Mufa M3, diferente a la descripción en SAP).
  • Bodega: Se selecciona la bodega del origen del material.
  • Lote: En materiales cuyo lote está visible, se selecciona el Lote correspondiente. Se puede no seleccionar también. En Ferretería, se muestra solamente como físico, debido a que esta no tiene un lote visible.
  • Solicitado: Si se ingresa la información de un proyecto con anterioridad, se puede indicar el material esperado que se retire. Esta columna no implica cambio de stock.
  • Entregado: se indica la cantidad entregada de material.
  • Instalado: Los técnicos registran la cantidad de material que instalan en el proyecto.
  • Devuelto: el material no utilizado se debe devolver y registrar.
  • Merma: En caso de material que se estropea y no se puede reutilizar, o retazos de cables menores a 50m que no se pueden reutilizar, se categorizan como merma.
  • Asignado a técnico: Material sobrante de la OTT que no se devuelve, se selecciona que queda en la posesión del trabajador.
  • Tránsito: Es la cantidad de material que está asignada al proyecto aún en posesió del técnico.
  • Nota: Utilizado para agregar anotaciones.
  • Técnico: se indica el trabajador al que se le entrega el material.

Al finalizar el proyecto, el tránsito debe quedar en 0. En caso que al finalizar una OTT queda el número distinto a 0, se debe investigar el motivo (si se reportó mal el material, si quedó material sin devolver, etc.)

  • Observaciones.

Se ingresan en esta ventana observaciones relevantes al proyecto relacionados a logística, por ejemplo, si se entregó algún material fuera del catálogo, si se registró mal un material y requiere cambio, etc.

  1. Generación de Informe

Desde esta sección, es posible subir registro fotográfico de las OTT, seleccionando el tipo de foto.

02 · Preventivos (OyM)

Desde terreno, la información subida corresponde a cada punto de un cuadrante.

  • Información por punto

Como encabezado, se indican la cantidad de puntos abiertos y cerrados.

La información de cada punto es la siguiente:

  • Fotos: A cada punto, le corresponden hasta 3 fotos: levantamiento muestra el estado en que se encuentra el punto al inspeccionar. En caso que el punto no tenga hallazgo, se deja solo la foto que indica que está OK. Si hay un hallazgo y se corrige este, se toman dos fotos más: la foto ANTES muestra el punto antes de la intervención. DESPUÉS muestra el punto tras ser intervenido. Estas fotos deben ser sacadas desde el mismo ángulo, para poder comparar lo que se hizo.
  • Dirección: se indica la dirección o esquina del punto.
  • Tipo de hallazgo: menú desplegable en que se indica el tipo de hallazgo, si es que hubo alguno.
  • Corrección: Se rellena una sugerencia genérica según tipo de hallazgo. Se puede modificar si se debe detallar más.
  • Brigada que corrige: se indica si la correción corresponde a brigada de línea u OyM.
  • Material: se agrega el material usado en correcciones de línea.
  • Comentarios: se da la opción de dejar alguna nota que valga la pena indicar por parte del equipo técnico que realiza el levantamiento.
